# Dedecube Core

Dedecube Core is a package designed to streamline the foundation of Flutter applications. It bundles and re-exports essential libraries and providing a unified starting point for scalable and maintainable development.

## Installation

Add `dedecube_core` to your dependencies in `pubspec.yaml`:

```yaml
dependencies:
  dedecube_http:
    git:
      url: git@github.com:dedecube/dedecube-core.git
      ref: v0.0.20
```
