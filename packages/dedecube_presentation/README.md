
# Dedecube Presentation

Dedecube Presentation is a package designed to support the UI layer of Flutter applications. It provides utilities, layout widgets, and a well-structured organization for pages, views, components, and UI-specific hooks — helping you build scalable and maintainable user interfaces with ease.

## Installation

Add `dedecube_presentation` to your dependencies in `pubspec.yaml`:

```yaml
dependencies:
  dedecube_presentation:
    git:
      url: git@github.com:dedecube/dedecube-presentation.git
      ref: v0.0.15
```
